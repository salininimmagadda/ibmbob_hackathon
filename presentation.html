Security Best Practices

Production-Ready Security

  • Never in Git: Credentials, passwords, API keys
  • Runtime Configuration: mqsisetdbparms for credentials
  • DSN Setup: /etc/odbc.ini on runtime server
  • Environment Separation: Dev, Test, Prod credentials
  • Encryption: AES-256 at rest, TLS 1.3 in transit
# Credential Setup (Runtime Server Only) mqsisetdbparms ACE_NODE -n jdbc::CUSTOMER_DB -u db_user -p password mqsisetdbparms ACE_NODE -n jdbc::ORDER_DB -u db_user -p password # DSN Configuration (/etc/odbc.ini) [CUSTOMER_DB_PROD] Driver = PostgreSQL Server = prod-db-server.company.com Database = customer_db

What Goes in Git:

✅ Message flows (.msgflow) | ✅ Subflows (.subflow) | ✅ ESQL code | ✅ Schemas (.xsd)

❌ BAR files | ❌ Credentials | ❌ Passwords | ❌ API keys
