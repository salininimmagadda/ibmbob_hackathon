  - `←`: Previous slide

  - `End`: Last slide

## 🔧 Customization

To customize the presentation, edit `presentation.html`:

### Change Colors:
```css
/* Line 13-14: Main gradient */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Line 48: Heading color */
color: #667eea;
```

### Add/Remove Slides:
1. Copy an existing `<div class="slide">` block
2. Update the slide number
3. Modify content
4. Update total slide count in navigation

### Adjust Timing:
```css
/* Line 35: Slide transition speed */
animation: slideIn 0.5s ease-out;
```
